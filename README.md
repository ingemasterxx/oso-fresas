# Oso Come Fresas 🍓🐻

Minijuego web: mueve al oso para comer las fresas que caen, esquiva el brócoli y gana premios.

- Controles: mouse o flechas ← → en la compu, deslizar el dedo en el celular.
- Fresa dorada = +5 · ❤️ regresa una vida · 🥦 quita una vida.
- Récord y premios se guardan en el navegador.
- Premios: ☕ 50 · 🍺 75 · 🎬🍿 150 fresas.

Para borrar récord y premios de un navegador, abre la página con `?reiniciar` al final de la dirección.
